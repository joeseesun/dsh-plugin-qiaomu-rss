# v0.7.0 — 链接收录与改写

- 新增默认关闭的实验室：验证邀请码、提交网页链接、申请列表、搜索与分页、状态恢复、失败重试、完成/失败通知。
- 可粘贴网页地址，也可右键正文链接复制或申请收录。复制使用实际点中的地址。
- 完成的申请直接打开阅读器的服务器改写；保留中文标题与原标题，并可继续使用原生 AI 伴读。
- 凭证在 Host 本机数据中保存，数据文件限制为 0600。没有通用凭证返回、Agent 提交工具或管理员界面。
- 进度检查复用 Cordis 的生命周期定时器，只有存在未完成任务时运行；网络失败退避，重启恢复。无损保留旧订阅、收藏与阅读状态，损坏的数据文件不再被空数据覆盖。
- 修复原有 Podscribe 方法缺少 Host Remote 标记的问题，与客户端描述符一致。

提交的链接发送到用户配置的乔木服务，改写会公开收录。此能力是网页收录和 AI 改写，不是任意音视频逐字稿。管理员与八语言全界面迁移另行处理。

- 新增模拟测试：邀请码拒绝、实例身份、幂等 UUID、丢失响应、404 恢复提交、重启恢复、失败重试、服务 origin 切换、中文标题与通知标记、响应体上限、拒绝重定向。
- 使用实际已安装 Cordis/Host 依赖执行 `tests/reading-context-store.mjs`，上下文及收藏状态持久化通过。

## 数据与回滚

`storages/qiaomu-rss/data.json` 的新增 `collection` 字段包含各服务 origin 对应的实例身份和邀请码，以及持久申请。没有迁移或删除旧字段。升级前建议备份该文件；回滚到 v0.6.0 可继续普通 RSS 阅读，但停止新收录功能。恢复旧版本时保留新数据文件，不用旧备份覆盖之后的阅读状态。
