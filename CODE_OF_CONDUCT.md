# 社区行为准则 / Code of Conduct

欢迎通过 Issue 和 Pull Request 讨论乔木 RSS。请尊重其他参与者，聚焦可复现的问题和具体改进，不发布骚扰、歧视、人身攻击或他人的私人数据。维护者可以编辑或移除违反这些原则的内容，并限制反复违规者参与。

安全漏洞和私密数据请按 [SECURITY.md](SECURITY.md) 报告。其他社区行为问题可通过仓库维护者的 GitHub 个人资料私下联系。

We welcome contributions and discussion. Be respectful, stay focused on reproducible issues and concrete improvements, and do not post harassment, discrimination, personal attacks, or private information. Maintainers may moderate content and restrict repeat offenders. Report security issues privately as described in [SECURITY.md](SECURITY.md).
